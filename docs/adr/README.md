# Architecture Decision Records

One short file per decision: `NNNN-title.md` (e.g. `0003-use-outbox.md`). Never edit an accepted ADR;
write a new one that supersedes it.

| #    | Decision | Status |
| ---- | -------- | ------ |
| 0001 | _your first decision_ | Proposed |

## Template

```markdown
# ADR NNNN: <title>

Status: Proposed | Accepted | Superseded by NNNN
Date: YYYY-MM-DD

## Context
What problem do we have, and what forces are at play?

## Decision
What we chose.

## Consequences
+ what gets easier
- what gets harder
```
